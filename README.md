# Sistema de apoyo a la toma de decisiones - IO II

Aplicación web con tres módulos: PERT/CPM, Inventarios y Teoría de decisiones.

**Stack:** HTML, CSS y JavaScript (frontend) · Node.js + Express (backend) · SQL Server (base de datos).

## Estructura
- `database/`: scripts SQL numerados (ejecutar en orden).
- `backend/`: servidor, rutas, controladores, algoritmos (`services/`) y pruebas.
- `frontend/`: portal y una página por módulo.
- `docs/`: informe técnico, manual de usuario y evidencias.

## Ejecución (por completar)
1. Copiar `.env.example` a `.env` y completar credenciales.
2. Ejecutar los scripts de `database/`.
3. `npm install` y `npm run dev`.
